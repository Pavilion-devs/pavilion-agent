# Demo video script (about 3 minutes)

**Setup:** run `python3 -m http.server 8765 --directory web` from the repo and open http://localhost:8765 full screen in a browser. Set Speed to 1×. Start with "Target (first run)" selected and nothing played. Record with QuickTime (File › New Screen Recording) or Cmd+Shift+5, with your microphone on.

| Time | On screen | Say |
|---|---|---|
| 0:00–0:20 | The page header and the Target question | "This is Pavilion. An analyst asks why a company's numbers moved, and whether it was the company or the whole sector. Here: why did Target's gross margin fall in fiscal 2022? What you're watching is a replay of a real recorded run, built from its logs." |
| 0:20–0:45 | Press **Play**. The Plan tab fills in | "H-MEM memory is empty: this is the first investigation. The Planner, on Nemotron Lightning through Meterless Nightshift, picks peers, excludes Kroger for a documented reason (its cost of sales excludes depreciation), and sets hypotheses on both sides: sector-wide and Target-specific." |
| 0:45–1:10 | Queries appear in the timeline. Click one query id chip to open the drawer | "The Investigator, on Nemotron Ultra, writes SQL against our Zetaris semantic layer over live SEC EDGAR data, SIC codes and BLS price indexes. Every query, its rows and the model receipt for every call are logged. Here are the exact SQL and rows." Close the drawer. |
| 1:10–1:50 | The Critic tab opens on round 1. Press **Pause** and scroll to the red cards; press **Play** again after | "Now the important part. The Critic re-ran every cited query in Zetaris and checked every number against the rows. It rejected four of five findings: leaving Dollar Tree out of the peer median because it didn't fit was cherry-picking; dollar figures that no query returned; price indexes misread as margin points; and year-end inventory used to rule out problems during the year. Each rejection goes back with a specific fix." |
| 1:50–2:15 | Rounds 2 and 3 appear, then the Memo tab | "Round two fixes three, round three fixes the last, and all five are approved. The memo states only approved findings: Target fell 4.64 points, the peer median fell 0.74, so 3.9 points were Target-specific. Every number carries the id of the query behind it." Click a query id in the memo. |
| 2:15–2:40 | Memory tab, then click **Best Buy (with memory)**, then **Show all**, then the Memory tab | "H-MEM turned the Critic's rejections into lessons. On the next question, Best Buy, it recalled four of them before planning, and the price-index mistake didn't come back. Best Buy's drop was mostly sector-wide: only 0.34 points were company-specific." |
| 2:40–3:00 | **Sponsor tech** tab | "Zetaris is the only data path, with six data-quality rules. Meterless Nightshift is the only AI provider, with a receipt per call. NVIDIA Nemotron Lightning and Ultra run the agents. The World Model and H-MEM engines are built from the Meterless specs, with tests. Pavilion: explanations an analyst can audit. Code at github.com/Pavilion-devs/pavilion." |

**Timing:** at 1× the Target replay takes about 40 seconds, so pause where you need to talk longer. You can press **Show all** at any point and narrate from the tabs instead.
